Data

Full Sample

To download a tar file containing the data for all clusters, click here. This file contains directories for each cluster housing the images, emission measure and temperature data files, and emission measure and temperature models, as described on the individual cluster webpages linked below.

A table containing various calculated values as described in Paper I for all clusters in the CEREAL sample is available here. The columns are: (1) cluster name, (2) RA of the cluster center used for the analysis (J2000 decimal degrees), (3) dec of the cluster center used for the analysis, (4) the surface brightness concentration calculated using 40 and 400 kpc apertures (csb_physical), (5) the error in csb_physical, (6) the surface brightness concentration calculated using \(0.15R_{500}\)- and \(R_{500}\)-sized apertures (csb_scaled), (7) the error in csb_scaled, (8) the centroid shift (w), (9) the error in w, (10) the excess nuclear luminosity in the 2-10 keV band (nuc_lum), and (11) the error in nuc_lum.

Individual Clusters

Below are two tables containing the information for the low-mass and high-mass CEREAL subsamples. For each cluster, there is the Planck name, the decimal coordinates, and the mass and redshift values derived from Planck. Note that we used corrected versions of the Planck masses for most of the analyses. Specifically, we applied a correction \(\log_{10} M_{500,\mathrm{true}} = -3.18 + 1.22 \log_{10} M_{500,\mathrm{PSZ}}\), as described in Paper II.

Clicking on the name of each cluster will take you to a webpage containing a cluster image as well as its emission measure and temperature profiles.
